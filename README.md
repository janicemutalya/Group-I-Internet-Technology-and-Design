# Group I Professional Portfolio

**Course:** Internet Technologies and Web Design  
**Project:** Professional Semantic Portfolio  
**Group:** Group I  
**Members:** David, Daniella, Janice, Oliver, Elton, Jesse, Victor, Juniorofamba, Oldrine and Vmilia

## Purpose
This project is a five-page HTML5 group portfolio demonstrating semantic structure, relative hyperlinks, lists, multimedia, accessible images, structured tables, HTML5 forms, documentation comments and Git/GitHub collaboration.

## Main Files
- `index.html` — Home page and group introduction
- `about.html` — Group profile, ordered list and description list
- `gallery.html` — Accessible image gallery, short HTML5 website preview video and embedded design resource
- `data.html` — Group skills and contribution table
- `contact.html` — HTML5 demonstration contact form
- `design/` — Sitemap and page wireframes
- `images/` — Local gallery images
- `videos/` — Short website preview video

## Technology Scope
The website uses HTML5 only. No CSS, JavaScript, PHP, database or external framework is required for this version.
