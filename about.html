About

Group I is made up of ten students working together on one semantic HTML5 portfolio for Internet Technologies and Web Design. Each member has a clear contribution so the final repository shows genuine teamwork and version-control practice.

The members are David, Daniella, Janice, Oliver, Elton, Jesse, Victor, Juniorofamba, Oldrine, Mpiima and Vmilia.

Project Milestones

  1. Review the assignment requirements and identify required HTML5 features.
  2. Create the sitemap and page wireframes before coding.
  3. Build the five interconnected semantic HTML pages.
  4. Add accessible images, captions and an embedded multimedia resource.
  5. Create a structured group skills table and an HTML5 contact form.
  6. Use Git and GitHub to record contributions from the ten members.
  7. Check links, accessibility, titles, comments and HTML structure before submission.

Important Technical Terms

HTML
HyperText Markup Language, used to structure content on a web page.
URL
A Uniform Resource Locator that gives the address of a resource on the Web.
HTTP
The protocol used for requests and responses between web clients and web servers.
DNS
The Domain Name System that maps readable domain names to IP addresses.
Web Browser
A client application that requests, receives and displays web resources.
Web Server
A server that receives web requests and returns resources such as HTML pages and images.
Git
A version-control system used to record changes to project files over time.
